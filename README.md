A one-liner entry for "The Meeting That Should Have Been One Line": a single sentence that could have replaced an entire pointless meeting.

Running `node main.ts` writes the entry line to `/output/entry.txt`:

> No discussion needed: we ship Friday, the budget's approved, and the only thing ever blocking the work was this meeting.

The line is 120 characters, one sentence, and stands alone with no context: it delivers the whole agenda (ship date + budget approval) and lands its sting in the final words — the meeting itself was the only blocker.

Node 22, standard library only.
